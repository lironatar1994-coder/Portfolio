# LA Webs

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Prospective Israeli business clients comparing website design and development studios, often visiting on a phone.

## Product Purpose
Demonstrate LA Webs' design and development quality through an exceptional portfolio and verified real websites. Help visitors explore work and start a project conversation.

## Capabilities and Constraints
Hebrew only, RTL. Studio positioning rather than a personal freelancer portfolio. Hard-coded showcases, no admin panel. Responsive mobile and desktop. Real production projects from the user's GitHub account. No fabricated testimonials, awards, commercial performance metrics, team sizes, or client outcomes.

## Brand Commitments
The user confirmed the studio name LA Webs. The user delegated reference research, selection, design planning, and the build. The design must be visually exceptional and focus on the work.

## Stack
Static HTML, CSS and JavaScript, generated with a dependency-free Node build. Static case-study pages preserve direct links and SEO. Production is https://lawebs.co.il, published through deploy.ps1 with a matching GitHub revision and rollback backup. Paid traffic starts at /lp/short/. Advertising tracking identifiers remain unset until verified in the user's advertising accounts.

## Evidence on Hand
See docs/project-inventory.md and docs/studio-research.md. Public production URLs and studio contact are verified live. Source assets belong to the user's projects.

## Product Principles
- Real work is the primary proof.
- Mobile receives a deliberate composition.
- Every project has a clear route to the live website.
- Motion respects reduced-motion preferences and never blocks reading.
