# LA webs — חבילת פרסום מוכנה לבדיקה

דף ההשקה שנבחר: https://lawebs.co.il/lp/short/

- research-20261006.md — מחקר, בחירת צבעים והבחירה בדף הקצר.
- google-ads-editor.csv — שתי קבוצות מודעות, מילות מפתח ומילים שליליות. הקמפיין והמודעות מסומנים Paused.
- campaign-summary.md — נוסחי החיפוש.
- meta-ads.json — שתי מודעות לפייסבוק ולאינסטגרם עם כתובות UTM.
- creatives — מודעת Feed ומודעת Story מוכנות.
- launch-plan.md — הגדרות ההשקה, המדידה ומצב החשבונות שנבדקו.

החומר הוכן. קמפיינים מלאים לא נשמרו בחשבונות בגלל הגדרה ראשונית שלא הושלמה. תגי המדידה כבויים עד למזהים מאומתים. אין תקציב מאושר ואין הוצאה על פרסום.

ליצירת נוסחי החיפוש מחדש: node scripts/ads-campaign.mjs. ליצירת התמונות מחדש: node scripts/prepare-paid-media.mjs עם שתי תצוגות האתרים המקומיות פתוחות.
