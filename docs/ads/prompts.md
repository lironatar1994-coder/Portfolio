# פרומפטים לקמפיין

## 1. מנהל הקמפיין השבועי

להדביק ב-ChatGPT, Claude או Gemini פעם בשבוע, יחד עם שני דוחות מ-Google Ads (בפורמט CSV): "מונחי חיפוש" ו"מודעות", של 7 הימים האחרונים.

```
אתה מנהל קמפיינים מנוסה ב-Google Ads לעסקים קטנים בישראל. אתה מנהל עבורי קמפיין חיפוש בעברית.

העסק: LA webs, סטודיו לעיצוב ופיתוח אתרים ומערכות בעיצוב אישי, בלי תבניות.
מה אנחנו מוכרים: אתרי תדמית (החל מ-2,500 ₪), מערכות הזמנה למסעדות ופיצריות, אתרים והרשמה לאירועים, קטלוגים דיגיטליים, דפי נחיתה.
עבודות לדוגמה: פיצת התנור (מערכת הזמנות), קורל אירועים (הרשמה לאירועים), פנחס רצון (משרד עורכי דין), מרים זליג (מאפרת כלות).
דף הנחיתה: https://lawebs.co.il/lp/ עם גרסאות ?t=tadmit, ?t=hazmanot, ?t=events, ?t=catalog.
המרה: פנייה (לחיצה על וואטסאפ, חיוג או שליחת הטופס בדף הנחיתה).
מבנה: 5 קבוצות מודעות (בניית אתר לעסק, אתר תדמית, מערכת הזמנות, הרשמה לאירועים, קטלוג דיגיטלי), מילות מפתח בהתאמת ביטוי ומדויקת, 28 מילים שליליות (חינם, וויקס, קורס, מדריך, AI, עבודה ועוד).

מצורפים דוח מונחי החיפוש ודוח המודעות של השבוע. תן לי:
1. מונחי חיפוש לא רלוונטיים להוספה כמילים שליליות (ברמת קמפיין, התאמת ביטוי), עם הסבר קצר לכל אחד.
2. מונחי חיפוש שהביאו פניות או נראים מבטיחים, להוספה כמילות מפתח, ולאיזו קבוצה.
3. קבוצות מודעות או מילים שמבזבזות תקציב בלי פניות, ומה לעשות איתן.
4. כותרות ותיאורים חלשים להחלפה, עם הצעות חדשות: עד 30 תווים לכותרת ועד 90 לתיאור. ספור תווים.
5. המלצה אחת לתקציב ולהצעות המחיר לשבוע הבא.

כללים: אל תמציא מספרים, ביקורות, פרסים או הבטחות. אל תציע דחיפות מלאכותית. עברית פשוטה וישירה.
```

## 2. תמונות למודעות (כשמרחיבים ל-Performance Max או רשת המדיה)

```
צור תמונת פרסום לסטודיו לבניית אתרים בשם LA webs.
סגנון: רקע שנהב חם (#f7f1e8), טקסט בפחם (#292521), נגיעות טרקוטה (#b84a2c). נקי, מודרני, הרבה מרווח.
בתמונה: יד מחזיקה מניפה של קלפים, וכל קלף הוא מסך טלפון של אתר אחר (מסעדה עם פיצה מתנור עצים, ערב נשים באווירה חמה, משרד עורכי דין רציני, מאפרת כלות). בלי טקסט על המסכים.
בלי לוגואים של חברות אחרות, בלי אנשים אמיתיים מזוהים, בלי טקסט בתוך התמונה.
גדלים: 1200×628, 1200×1200, 960×1200.
```

את הטקסט מוסיפים במודעה עצמה, לא בתמונה.

## 3. בקשת ביקורת מלקוח אמיתי

ביקורות מזויפות פוגעות באמינות, מפרות את המדיניות של גוגל וחוקי הגנת הצרכן, ועלולות לגרום להשעיית החשבון. במקום זה, שלחו ללקוחות קיימים (קורל, מרים, פנחס, דפוס ראובן, ליבי יהלומים, בדרך אליך):

```
היי [שם], כאן לירון מ-LA webs 🙂
שמחתי מאוד לעבוד איתך על האתר. אם יש לך דקה, ביקורת קצרה בגוגל תעזור לי מאוד:
[קישור לביקורת מפרופיל העסק בגוגל]
מספיק משפט אחד, למשל מה הכי אהבת בתהליך או באתר. תודה!
```

את הקישור לביקורת מקבלים בפרופיל העסק בגוגל: "בקשת ביקורות".
